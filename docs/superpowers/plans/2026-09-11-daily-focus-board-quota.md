# 每日聚焦：候选板块平衡（主板 3 : 中小板 3 : 创业板 2 : 科创板 2） Implementation Plan

**Goal:** 每日聚焦在分数达标的前提下按板块平衡候选，推荐比例 主板 : 中小板 : 创业板 : 科创板 = 3 : 3 : 2 : 2；某个板块没有合格候选时不用硬凑，把名额让给其他板块，候选充足时尽量凑满 10 只；某个板块候选很多时也可以多拿几个。

**Architecture:** 板块归属是纯代码前缀规则，放在前后端共用的 `src/domain/board.ts`，服务端用它做配额、界面用它做标签（因此旧的冻结记录也能显示板块）。配额的实现放在策略层唯一的选取函数里（`selectWithIndustry`），只决定「谁能进来」，展示顺序仍按最终分排序；选取诊断随冻结记录留档。方法版本升到 `daily-focus-v6`。

## 已知边界

- 板块配额是「推荐值」，不是硬约束：当某个板块合格候选不足，或行业上限把候选挡住时，最终分布会偏离 3:3:2:2，界面与诊断都会写出实际分布，不会假装达标。
- **已经冻结的历史记录不会被重算**：2026-09-11 的冻结名单仍是 `daily-focus-v5` 选出的（主板 5 / 中小板 4 / 创业板 0 / 科创板 1），界面会如实显示这一分布；`daily-focus-v6` 从下一次冻结（或盘中预览）开始生效。
- 板块只按代码前缀判定，不使用行情里的板块字段，因此不会因为数据源字段缺失而漂移。
