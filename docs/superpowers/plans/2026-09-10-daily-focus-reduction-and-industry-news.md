# 每日聚焦：行业名称、减持排除与行业新闻角度 Implementation Plan

**Goal:** 在每日聚焦界面上（1）热门行业显示具体行业名称；（2）把有股东减持（尤其大幅减持）的股票从候选中排除并可审计；（3）把热门行业新闻作为舆情的一个独立角度展示并计入行业共振分。

**Architecture:** 减持识别与行业新闻归属都是纯文本规则，放在可单测的纯函数里；每日聚焦策略只接收装配好的输入，新增一个不可放宽的硬门槛与一个行业共振子项，因此方法版本升级到 `daily-focus-v4`。行业新闻的归属在行业分析层完成（只有新闻来源、且标题命中行业别名的事件才归属行业），每日聚焦层只消费结果，不重复实现行业匹配。落地时发现公告适配器的范围证明在真实数据下永远无法成立（合并窗口条数超过分页上限、且 `display_time` 会溢出到相邻自然日），导致公告/新闻事件从未进入每日聚焦；因此本计划同时修复公告逐日取证，否则前两项功能在生产中不会生效。

## 任务 1：减持识别纯函数

- [x] `server/shareReduction.ts`：`classifyShareReductionText(text)` 返回 `null` 或 `{ level: "major" | "minor"; matched: string[] }`。
- [x] 排除没有实际卖出动作的表述：`未减持`、`不减持`、`尚未减持`、`未实施减持`，以及没有“结果/完成/实施”证据的 `终止/放弃/取消减持`；`承诺事项的说明` 等非行动公告也不计入。
- [x] 只处置可转债、公司债等非股份权益且未提及股份/股票的，不算股份减持。
- [x] 大幅减持：`控股股东`、`实际控制人`、`一致行动人`、`5% 以上股东`、`清仓/全部持股`、`大幅/巨额/大额`，或“减持不超过 X%”中 X ≥ 2（`减持至5%以下` 这类持股比例变化不读成减持比例）。
- [x] 单测覆盖正例、否定例、可转债例与大幅判定；并用数据库里 112 条真实公告标题做过回归核对（7 条“未减持/终止”全部正确跳过）。

## 任务 2：每日聚焦硬门槛与行业新闻评分

- [x] `DailyCandidateInput` 新增可选 `shareReduction`、`industryNews` 字段并纳入 `validInput` 校验与审计快照的可变引用隔离。
- [x] 资格门槛：命中减持即排除，`major` 记 `majorShareReduction`，其余记 `shareReduction`，两者都出现在 `exclusionCounts`。
- [x] 行业共振分改为：文本热度 2 + 情绪方向 2 + 行情强度 3 + 广度 2 + 关系 1 + 行业新闻条数 1 + 行业新闻方向 1 = 12 分；没有行业新闻时后两项记 0，不把缺失当满分。
- [x] `DAILY_FOCUS_VERSION` 升到 `daily-focus-v4`。
- [x] 盘中关注（live fallback）列表应用同一条减持排除。

## 任务 3：行业新闻归属

- [x] `industryAnalytics.ts`：只有 `sourceKind === "news"`、非公司公告、且 **标题** 命中行业名称/别名的事件才按关键词归属行业，正文顺带提及不扩散。
- [x] `IndustryPulse` 新增 `newsEvidence`（最新 5 条非论坛事件，行业级优先，带 `scope`、`sourceKind`、`url`）。

## 任务 4：服务装配与审计

- [x] `dailyCandidateService.buildInputs`：按当日数据窗口内已核验的公告计算每只股票的减持信号，同级取最新、跨级取更严重的一条。
- [x] 每只候选装配 `industryNews` 评分输入与 `industryNewsEvidence` 展示证据，并写进入选理由。
- [x] `dataQuality.shareReductionExclusions` 记录被排除股票的减持证据，界面上可展开复核。

## 任务 5：界面

- [x] 候选行显示“热门行业：航海装备Ⅱ / 行业：教育”这类具体行业名。
- [x] 展开明细新增“行业舆情”角度：行业名、热度、方向、行业级/成分股新闻列表与来源链接，并说明其在行业共振分中的占比。
- [x] 排除计数显示中文标签，明确“减持 / 大幅减持”，并说明依据的是当日窗口内的公告。

## 任务 6：让公告真正可用（落地时发现的前提问题）

- [x] 公告按自然日逐日分页取证：合并窗口（月末叠加半年报可达 1.5 万条）无法在规定页数内穷尽，单日窗口可以。
- [x] 逐日证明区间覆盖实际返回的时间戳（`display_time` 可以早于 `公告日期`），否则整批公告会被判为区间外证据而作废。
- [x] 合并相邻自然日时允许区间重叠、拒绝缺口；未证明穷尽的单日窗口打印诊断日志。
- [x] 修复后真实数据验证：`authority` 由 `degraded` 变为 `available`，2026-09-10 冻结榜出现 12 只“大幅减持”与 10 只“股东减持”排除记录。

## 已知边界

- 财经快讯与个股新闻适配器仍按设计“不提供范围证明”，因此市场级行业新闻（如“电子板块走强”这类快讯）当前不会进入每日聚焦；行业舆情角度目前由成分股公告与新闻构成。要放开需要为这两个源补上可审计的窗口证明。
- 讨论源（股吧/微博/雪球）同样缺少 `queryFrom/queryTo` 证明，因此“讨论升温”在未配置授权论坛源时保持为 0，而不是伪造数值。
