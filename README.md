# 潮汐 · A 股舆情雷达

潮汐是一个面向中国 A 股研究场景的实时舆情工作台。它持续汇总已配置来源中的公开线索，将线索关联到沪深北股票池，再把情绪、热度、共识、来源质量与当日价格表现整理成可追溯的研究视图。

界面基于 [shadcn/ui](https://ui.shadcn.com/)（Tailwind CSS 4 + Radix UI）构建，保留 A 股红涨绿跌语义色与深色导航侧栏。

本项目不提供买入、卖出、目标价、未来收益或具体交易时机建议。

## 已实现功能

- 实时全市场股票池：从东方财富行情接口读取沪深北股票，不再使用固定样本股票。
- 每日行情沉淀：全市场当日行情与按需回填的个股日线保存到本机 SQLite，为后续历史分析准备数据。
- 每日舆情快照：当日已评分股票的线索聚合结果（异动分、文本方向、情绪因子、主题、摘要）按“股票代码 + 交易日”沉淀到 SQLite，供历史异动回看。
- 全量线索聚合：获取当前配置的财经快讯、上市公司公告与真实用户讨论，去重后统一入库并关联股票。
- 自动更新：服务端后台按周期定时抓取并落库，且区分交易时段：交易时段（北京时间 9:15–11:30、13:00–15:00 的交易日）抓取行情+全部线索；休市期间（午休、晚间、周末与节假日）行情沿用本地已存数据（不重复请求），财经快讯、上市公司公告与论坛讨论仍照常抓取。接口只读取缓存快照，异动候选里的排序、筛选、分页均在内存完成，不再触发远端抓取；首页、全市场、自选股和个股页每分钟静默刷新，失败时保留上次成功的真实数据并提示停更。
- 自选股优先：自选股存入本机 SQLite，首页默认先展示自选股舆情，重启后仍保留。
- 异动候选（每日异动）：展示全市场股票，符合成交额前 150 / 涨幅前 100 / 跌幅前 50 条件的股票额外标注「异动标签」；并提供交易日选择器查看历史交易日的行情与舆情（当日舆情按交易日沉淀为快照）。搜索始终在全市场范围内进行；排序、筛选、搜索与页码会在离开页面（如查看个股详情）后自动保留，返回时恢复原条件。
- 每日聚焦：收盘后仅在完整沪深行情、经服务端范围证明的用户讨论与新闻/公告、以及五个可验证讨论基线窗口均齐备时，冻结 3–10 只前视候选；冻结记录、来源水位、特征、T+1 至 T+3 结算与成本后的历史超额均可审计。基线或覆盖不足时不会伪造零值，会保持待定或按截止时间标为不可用。
- 全市场筛选：由服务端搜索、排序和分页；暂无线索的股票显示空分，不生成模拟评分。
- 个股核验：展示实时价格、东方财富历史日线、舆情因子、原始线索与关联理由；分时线以昨收为中轴（涨在上、跌在下），日/周/月线为标准蜡烛图并支持十字光标查看每日 OHLC、涨幅与成交量。
- 行业信息分类：使用东方财富全市场行情中的行业字段，将股票和行业线索归类，并在首页、异动候选和个股详情展示行业信息类别、行业舆情热度、行业行情强度与当前关系。
- 热点行业与涨幅关系：文本热度只读取新闻、公告和用户讨论，行情强度只读取行业成分股相对全市场的当日表现；“舆情交易双热”表示当前两者同向，“舆情升温、价格未确认”表示热度已升温但当日价格尚未确认。行业同行部分与个股相对行业部分只是已实现的描述性拆解，不代表因果或未来涨幅预测。
- 数据源状态：逐项展示东方财富行情、快讯、公告和各用户讨论来源的连接状态与数据量。
- 纯中文界面：产品标题、导航、按钮、状态、指标和错误信息均使用中文。

“全部线索”只指所有已配置且成功返回的来源记录，不代表全网全部内容。东方财富股吧目前按自选股和成交活跃股票采集公开帖子元数据；微博按股票名称采集公开搜索结果的近期帖子；雪球需要用户自行提供合法会话，并按其公开接口做“股票名全站关键词搜索 + 个股时间线”抓取；同花顺圈子等待平台授权接口。任何来源失败都不会使用模拟帖子补位。

## 启动

需要 Node.js 22+ 与 pnpm。

```bash
pnpm install
pnpm dev
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。开发模式同时启动界面服务和本地接口服务：

- 界面：`127.0.0.1:4173`
- 接口：`127.0.0.1:8788`

生产构建与本地运行：

```bash
pnpm build
pnpm start
```

### 部署到服务器

项目附带一键部署脚本 `deploy.sh`（服务器地址、端口、账号已内置，按需修改脚本头部的 `SERVER_HOST` / `SERVER_PORT` / `SERVER_USER` / `REMOTE_DIR`）：

```bash
./deploy.sh          # 首次运行会交互式要求输入 SSH 密码，后续命令复用同一条连接
./deploy.sh --check  # 只做本地打包检查，不上传
SSH_PORT=22022 ./deploy.sh   # SSH 端口不是 22 时
```

脚本流程：本地打包（排除 node_modules/dist/data/.git）→ 上传 → 服务器自动检测并安装 Node 22 与 pnpm（缺失时）→ 安装依赖、构建 → 写入 `.env`（API 端口）→ 重启服务（pid 文件 + nohup，日志 `tide.log`）→ 健康检查。部署完成后打印访问地址；若外网不通，按提示在服务器防火墙或云安全组放行服务端口。

## 实时数据链路

当前版本通过后端读取东方财富全市场行情、个股日线、财经快讯、上市公司公告与重点股票的真实用户讨论。原始接口不会直接暴露给浏览器；每日行情、线索元数据、每日舆情快照和自选股统一保存在 `data/tide-live.sqlite`。外部来源故障时只使用之前保存的真实数据，不会混入演示数据。每日舆情快照按交易日增量累积：只有应用当天运行并完成聚合的交易日才有对应舆情快照，更早日期仅保留行情数据（舆情列如实显示空值）。

公开网页接口可能调整、限频或附带商业使用限制。当前实现适合本地研究和技术验证；公开运营或商业使用前，必须取得数据提供方的书面授权，并改接有服务协议的正式数据源。

### 接入获授权论坛数据

项目预留了标准化论坛数据接口。只有返回来源许可编号的数据才会被接纳；默认不配置、不抓取未授权股吧内容。配置示例：

```bash
FORUM_FEED_URL=https://your-licensed-vendor.example/v1/forum/clues \
FORUM_FEED_TOKEN=your-private-token \
pnpm dev
```

接口需返回版本 `1.0`、来源编号、来源名称、许可编号，以及带稳定编号、股票代码、标题、必要摘要、永久链接和发布时间的线索。作者身份默认不采集。令牌只放环境变量，不写入仓库。

### 真实用户讨论

讨论层按可配置周期更新（`TIDE_DISCUSSION_REFRESH_MS`，默认五分钟，最低一分钟），覆盖全市场讨论热点并驱动全市场热度排序：

- 东方财富股吧帖子：每轮扫描当日涨跌幅与成交额前列的约 300 只异动股票（含全部自选股）的最新帖子，并用股吧全市场热帖精选与热门排行补充长尾热点，覆盖当天有讨论的股票而不限于重点股票。
- 东方财富股吧评论：对每轮评论数最多的一批热门帖读取顶层公开评论（借鉴 [zcyeee/EastMoney_Crawler](https://github.com/zcyeee/EastMoney_Crawler) 的“帖子 + 评论”采集边界，直接使用公开 JSON 接口，不运行浏览器自动化）；同样不保存昵称、用户编号等身份字段。
- 雪球讨论：使用用户自行提供的合法会话抓取。雪球接口由阿里云 WAF 保护，服务端 Node 直连（即使携带完整 Cookie）必然命中挑战页，因此会话校验与数据抓取都通过真实 Chromium 页面内同源请求完成（先无头，命中风控自动改用有头窗口）。数据策略：对每只股票同时做「股票名全站关键词搜索」（`query/v1/search/status.json`，覆盖话题/长文/讨论中对该股的提及）与「个股时间线」（`query/v1/symbol/search/status.json`），覆盖整个股票池、按轮转游标分多轮扫完、结果按线索去重。配置方法（任选其一）：

  1. 推荐：用你的常用浏览器（Chrome / Edge / Brave）打开 [xueqiu.com](https://xueqiu.com) 并登录，然后运行
     `pnpm xueqiu:session`，程序读取该浏览器里的雪球会话并保存到 `data/xueqiu-cookie.txt`
     （读取前需要短暂退出该浏览器，完成后自动重新打开；可用 `--browser` / `--profile` 指定目标，`--dry-run` 预演）；
  2. 网页“数据源 → 雪球讨论 → 连接雪球”点“打开浏览器登录”：本机弹出浏览器扫码登录，成功后该窗口常驻用于数据抓取（可最小化，请勿关闭）；
  3. 兜底：F12 → Network 面板 → 刷新页面 → 点击任意 `xueqiu.com` 请求 → 复制请求头完整 `Cookie`，在网页对话框粘贴导入（同样走真浏览器校验），或写入 `.env` 的 `XUEQIU_COOKIE` 后用 `pnpm xueqiu:verify` 验证。

  真浏览器在本机可用时雪球讨论自动接入；远程无显示器部署时无法建立浏览器会话，雪球讨论保持关闭或降级，绝不伪造数据。
  > 抓取已默认开启（`server/userPosts.ts` 顶部 `XUEQIU_FETCH_ENABLED = true`）；如需彻底停用改为 `false` 即可。可用 `pnpm xueqiu:probe` 实测「名称全站搜索 / 个股时间线」各能返回多少条，便于在接入前评估覆盖量。
- 微博讨论：对当日异动股票（成交额前 150 + 涨幅前 100 + 跌幅前 50 的并集）按股票名称做公开搜索，覆盖全部异动股票。微博搜索接口在真实 Chromium 页面内同源请求即可访问（匿名访客令牌，无需登录，页面首次加载自动获取）；每轮预算 150 秒、并发 4 路，空结果自动重试一次。只取 72 小时窗口内的公开微博，仅保存标题摘要、时间与原始链接，不保存昵称、用户编号等身份字段；未安装浏览器的环境自动保持关闭。
- 同花顺圈子：实测帖子列表接口要求登录，服务协议禁止未授权自动抓取，因此默认关闭并等待授权数据接口。

用户讨论在数据模型和界面中以“用户讨论”独立分类，与“新闻事件”“公司公告”分开统计；语义层仍进一步标注宏观、政策、行业、公司或海外事件。行情仍按实时周期更新，讨论每五分钟更新一轮，因此基于评论与新闻舆情的全市场综合评价与排序每五分钟刷新。

## 东方财富行情与本地保存

项目不再要求安装 free-stockdb。服务启动后从东方财富读取全市场行情，整批校验成功后按“股票代码 + 交易日”原子写入 SQLite。个股详情需要历史日线时，会从东方财富回填并先写入数据库再展示。

部分网络环境会拒绝连接东方财富历史主机 `push2his.eastmoney.com`（TLS 握手后无响应）。此时日/周/月 K 线自动改由腾讯行情镜像（`ifzq.gtimg.cn`，同一交易所公开行情）回填，并在数据源状态页明确标注“腾讯行情镜像”，不隐瞒来源。个股分时线使用东方财富实时分时接口（`trends2`，主备双主机），盘中每分钟更新一次点、每 15 秒自动刷新。沪深股票均有镜像数据；北交所股票在镜像无数据时保持“历史价格暂不可用”，不会生成模拟曲线。

同一交易日重复同步只更新记录，不会无限增加行数；分页失败或数量异常时整批拒绝，页面继续使用上一个完整的真实快照并标记停更。

## 评分说明

异动分用于发现变化，不代表上涨概率：

```text
异动分 = 35% 讨论增速
       + 25% 互动热度
       + 20% 来源广度与质量
       + 20% 情绪位移绝对值
```

文本方向以 50 为中性，只读取文本情绪、观点共识、来源质量和时效；价情共振分在此基础上另行加入价格确认。股票在当前窗口没有有效线索时，两项分数都为空，不用中性值掩盖“没有证据”。实现位于 `src/domain/scoring.ts`。

## 情绪分析准则

单条文本情绪由 `server/sentiment.ts` 的 `classifyText` 判定，输出偏正面 / 偏负面 / 多空分歧 / 中性四类，可解释、可回查命中关键词：

- 正面词（权重 1）：增长、利好、涨停、回购、赚、浮盈等金融与论坛多头表达。
- 负面词（权重 1）：下调、减持、亏损、跌停、套牢、破发、痛失等空头表达。
- 强烈负面（权重 2.5）：咒骂、诅咒、泄愤与愤世表达（天收、报应、割韭菜、圈钱…），单次命中即判负。
- 反讽 / 愤世（权重 1.5）：王侯将相、权贵、垄断、呵呵、就这、离谱等带讥讽或怨气的表达。
- 反问 / 质疑句式（权重 1.5）：凭什么、问谁服务、有什么用、不过如此等负向质问。
- 弱负面（权重 0.5）：哎、唉、可惜、无奈等叹气语气，单独不足以判负。

判定同时考虑否定（“不看好”→“看空”）、强调（“严重亏损”更强）与弱化（“略有好转”更弱）；多个词命中取最长、不重叠匹配，避免“割韭菜”与“韭菜”重复计分。正负证据并存且强度相当判为“多空分歧”，否则中性。

股吧评论的情绪只取评论正文，剥离“在《帖子标题》下的评论：”前缀，避免帖子标题的情绪污染评论情绪。

## 本地接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| 读取 | `/api/health` | 应用与真实数据健康检查 |
| 读取 | `/api/dashboard` | 舆情雷达首页 |
| 读取 | `/api/industries` | 行业分类、热点行业、关系与方法论 |
| 读取 | `/api/industries/:code` | 单个行业的线索证据、成分股与收益拆解 |
| 读取 | `/api/stocks` | 全市场服务端搜索、筛选、排序和分页（异动股带异动标签；`date` 参数可查历史交易日的行情与舆情快照） |
| 读取 | `/api/trade-dates` | 已保存完整行情的交易日列表（供异动候选页日期选择） |
| GET 读取 | `/api/daily-candidates` | 当前交易日的每日聚焦：有冻结记录时返回不可变记录，否则返回只读预览；可用 `?date=YYYY-MM-DD` 读取指定冻结/重建记录 |
| GET 读取 | `/api/daily-candidates/performance?window=20\|60` | 仅统计前视冻结、已完成结果的 20/60 日表现；含成本基点、净超额、分组与 3 交易日块置信区间 |
| 读取 | `/api/stocks/:code` | 个股舆情、线索与历史行情 |
| 读取 | `/api/events` | 全部已聚合事件 |
| 读取 | `/api/watchlist` | 读取自选股 |
| 写入 | `/api/watchlist/:code` | 加入自选股 |
| 删除 | `/api/watchlist/:code` | 移出自选股 |
| 读取 | `/api/system` | 数据来源和覆盖状态 |
| 刷新 | `/api/system/refresh` | 主动刷新全部真实来源 |

单条文本解析入口已经从界面和接口中完整删除。

## 产品与合规边界
